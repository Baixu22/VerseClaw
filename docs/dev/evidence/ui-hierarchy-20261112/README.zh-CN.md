# 会话界面层级优化

本轮调整了左侧会话管理和会话顶部。深色参考所有者提供的 Codex 截图，视觉验收使用 ego-browser 中的实际生产构建，数据来自仓库的浏览器 Host API 夹具。全部自动化证据均为 `driven_by: agent`。

| 已确认的问题 | 调整后的行为 |
| --- | --- |
| 项目和会话使用常亮胶囊，另有原生子会话下拉框 | 顶部从 48px 减至 40px；无底框标题负责身份与导航，根会话示例的常驻控件从 6 个减至 5 个 |
| 会话搜索上方堆叠管理操作 | 标题菜单直接聚焦搜索；来源、派生会话和关系详情集中展示；检查点、分叉、接力进入「更多」 |
| 关闭菜单时卸载执行迁移组件 | 迁移弹窗保留，关闭后焦点返回「更多」；目标选择复用现有 Select |
| 深色侧栏与正文使用同一底色 | 侧栏 `#272929`，正文和顶部 `#2D2D2B`，菜单 `#3D3D3B`，输入框 `#474745` |
| 720px 窗口、275px 侧栏和长标题组合出现 43px 重叠 | 标题随可用空间收缩，末端与右侧操作区保留 8px 间隔 |
| 已展开的会话仍显示子项数量，父子字号不同 | 数量仅在折叠时出现；父子行共享 14px 字号，以缩进和连线表达关系 |
| 恢复后的缓存仍提示历史风险；工作区面板遮掉环境按钮 | 缓存恢复后静默，环境入口在工作区面板打开时仍可访问 |

## 验收结果

- ego 六组主题/宽度检查通过：浅色、深色 × 1280、960、720px。菜单在窗口内，标题和操作区不重叠。
- 父子会话往返保留各自草稿；搜索、方向键、Escape 返回焦点通过。
- 长标题、侧栏两按钮、展开计数和减弱动画检查通过。
- 迁移恢复使用浏览器专用 Host 夹具验证弹窗和关闭行为；没有执行迁移。
- 9 个相关单测文件共 76 项通过；色板与弹窗修改后复查的 15 项属于这 76 项的子集。
- Vite 构建、node/web/test 类型检查、i18n 检查通过；定向 ESLint 为 0 error。Harness 按当前真实 diff 校验，通过并列明 8 条既有改动路径。
- Electron 自测在 `firstWindow` 的 30 秒建窗等待中超时，界面断言未开始；改动前也出现相同超时。测试自己的进程已回收。
