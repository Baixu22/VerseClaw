# 会话执行托盘

新会话启动前，输入框上方显示项目、分支及执行设置。运行开始后关闭浮层并收起启动区；已有历史或已暂停的会话保持收起，新建空会话时再次显示。任务进度仍按真实状态展示，步骤按需展开。

点击分支名打开独立的分支选择区域，可搜索并切换现有分支，键盘方向键导航、Escape关闭并返回入口。当前分支保留勾选标记。更多按钮打开执行设置，默认主目录不显示「本地」按钮；链接工作树显示「工作树」入口。默认生成唯一的 `codex/task-…` 分支，点击「创建并打开」即可从当前分支的已提交内容建立新工作树。自定义分支名和起点收在「改名 / 起点」中，创建路径由既有 Git 服务决定。

执行设置列出主目录和已有工作树。选择目录时先保存当前会话草稿与界面状态，再恢复目标目录的会话；新建目录以空输入开始。分支切换原地更新当前位置。运行开始后，启动区和其浮层关闭。

失败原因在操作旁显示。已创建目录但打开失败时，可以重试打开同一工作树。重复点击不会重复派发创建；晚到的操作结果不会把另一个会话跳转到旧目标。权限、审批、分支占用与 Git 写入继续由原 Host API 处理。

视觉由 Carbon 根据用户参考图决定：输入区22px圆角，内缩托盘16px圆角，设置浮层18px圆角。灰阶实底和轻描边区分画布、托盘、输入和浮层；窄窗保留位置与更多入口，完整分支信息在浮层查看。

创建过程中，进度卡原位替换输入区，按实际操作依次显示保存会话、创建工作树和打开会话。选择「留在当前会话」会等待创建结算后恢复原草稿，托盘保留已就绪目录的打开入口；失败可重试同一次创建或返回会话。审批与提问继续优先显示。
