# 会话引导与接力

运行中输入补充内容后，发送按钮按默认方式排队。旁边的“发送方式”提供立即执行的选项：结束后发送、加入当前运行、停止后发送，以及修改任务目标。Enter 排队，Ctrl/Command+Enter 引导，Ctrl/Command+Shift+Enter 停止后发送，Shift+Enter 换行。普通会话沿用队列；长任务提供引导和打断能力。

顶部更多菜单和输入区会话操作给出两种延续方式：分支复制现有上下文并打开新会话，下一条消息由用户发送；摘要接力先展示可编辑内容，点击“创建并发送”后打开新会话并提交首条消息。准备过程显示真实忙碌状态，运行中或会话身份尚未就绪时显示禁用原因。

接力窗口优先显示内容，来源和提示收在可展开详情里。恢复接力使用已保存的操作和草稿；发送结果未确认时先核对记录，再决定恢复。草稿、源会话代次、子会话身份和首发身份仍由现有Workspace与Runtime机制保存。

整理上下文显示一份当前用量、被截断消息提示和可选保留要求。历史、缓存统计和技术说明按需展开。确认后沿原Host API执行压缩并刷新历史，运行中禁止压缩。对话框与输入区共用实色灰阶材质，窄窗口保留可达的确认操作。

Carbon查看首版真实Electron截图后，确认以下细节：发送菜单明确“立即发送此草稿”，停止按钮使用次级灰底；摘要接力排在分支继续之前，仅高上下文压力显示推荐，分支使用对话图标。操作浮层与对话框采用18px圆角、100%不透明灰阶底色；标题16px无衬线，输入框使用灰色聚焦描边。接力正文高200px，保留要求高88px，确认按钮高34px。队列成功排空静默刷新，失败提示保持可见。
