# 会话中的工具操作

工具摘要使用较小字号，展开和收起按内容高度过渡。系统开启减少动态效果时立即切换。左侧回合导航的预览卡右上角可以标注当前回合，书签标记可直接跳转，顶部书签按钮循环跳到已标注回合。标注保存在当前设备，并按项目、会话和历史记录身份隔离。

模型说明与最终答复按发出顺序阅读。运行摘要根据最近一次输出显示思考、处理工具结果或撰写回复；等待用户回应时优先显示待办操作。展开处理过程可以继续阅读已记录和正在到达的思考摘要。

并行调用各自保留状态。某个调用失败后，折叠摘要标明失败目标，同时继续显示仍在执行的调用。工具详情分别展示参数和回执。模型继续回答或正常结束时，失败记录仍可展开查看。

会话正文、工具操作和输入框共享可用宽度。工具操作按助手说明分组：说明后连续进行的读取、写入、修改、搜索、网页访问和命令，默认合成一条可展开摘要。新的说明开始下一组。

折叠摘要采用图标与纯文本，显示最新正在进行的动作和目标。新调用的文字从左向右进场一次，运行期间持续白色 shimmer，旁边的 Lucide 图标循环播放动效：文件线条绘入、搜索摆动、地球经线转动、命令光标闪烁。日志追加保持动画连续。展开后，每条工具和命令记录采用带背景、进度填充和计时的调用条，行为图标保持静态。后台组、完成、停止、失败和等待结果的图标也保持静态，悬停不会启动动画。减少动态效果时文字、图标与进度静态可读。

方法图标使用现有 Lucide 图标库，按工具名称、已捕获目标与浏览器动作匹配。目录、代码、图片、PDF、表格、配置分别使用对应文件图标；Git 区分分支、差异、提交与合并，命令区分测试、构建和包管理，浏览器区分点击、截图与滚动。记忆、数据库、网络、计划与子代理也有对应图标。未知方法使用工具图标。

展开组可以逐项查看参数、结果、命令输出和文件修改。工具调用与迟到结果使用同一调用身份配对，命令输出复用会话终端。运行中的历史记录与最新事件合并显示，迟到结果留在原操作下。交互请求继续在输入区处理，最终答复与交付资源保持可访问。

分组消费现有 `UserRunCard`、消息与运行表面；会话和执行 owner 继续决定调用、权限、完成状态和重试。显示状态复用现有会话保存机制，工具参数和结果作为文本展示。

变更审查条位于输入框与审批共用的外层。审批期间可以继续查看变更，原输入保持挂载，处理结束后恢复草稿。
