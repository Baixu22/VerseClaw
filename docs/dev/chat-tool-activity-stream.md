# 会话中的工具操作

会话正文、工具操作和输入框共享可用宽度。工具操作按助手说明分组：说明后连续进行的读取、写入、修改、搜索、网页访问和命令，默认合成一条可展开摘要。新的说明开始下一组。

运行时，摘要显示最新实际操作与目标。图标进入时播放一次白色扫光，文字持续 shimmer；展开后动画移到详情中的当前操作。完成后显示执行过的操作类别，手动展开和折叠状态继续保留。减少动态效果时显示静态可读文字。

展开组可以逐项查看参数、结果、命令输出和文件修改。工具调用与迟到结果使用同一调用身份配对，命令输出复用会话终端。运行中的历史记录与最新事件合并显示，迟到结果留在原操作下。交互请求继续在输入区处理，最终答复与交付资源保持可访问。

分组消费现有 `UserRunCard`、消息与运行表面；会话和执行 owner 继续决定调用、权限、完成状态和重试。显示状态复用现有会话保存机制，工具参数和结果作为文本展示。

验证入口是 `harness/specs/tasks/chat-tool-activity-stream-20261123.md`。单测覆盖历史与运行记录合并、迟到结果配对、命令归属、状态与作用域；Electron 旅程覆盖四语、明暗主题、375px 窄窗、工作区面板、键盘、减少动态效果和实际左右边界。
