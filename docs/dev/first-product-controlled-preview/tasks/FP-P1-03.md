## Goal（用户可见结果）
用户在产品内一处显式打开「DCS Coding Preview」，界面随后显示 runtime 已确认；关掉后 runtime 也确认已回到基线。整个过程无需碰 env、无需读文档。

## Why this exists
`FP-P0-04` 造了 ack 状态机，本任务把它变成**一个产品化入口**：把散落的 5 个可写 flag 收敛为一个 Preview 开关（内部仍按需组合），并绑定 workspace 与权限上下文。没有这一步，「显式 opt-in」在产品层面仍是专家操作。

## Non-goals
- 不做 default-on
- 不新增能力 flag
- 不把排除项（RM 注入 / SEKB 自动写回 / Browser 无监督 / VToken）纳入这个开关
