## Goal（用户可见结果）
会话进行中重启应用或 gateway，用户回到可继续工作的状态；出问题时一次 kill 操作让增强立刻停止，且长时会话不会残留半生效状态。

## Why this exists
L4 现状只有 scripted dry-run 和短路径 toggle/restore，不是长时增强会话的生产 rollback 证据（Codex 判定）。首发承诺「kill/rollback 可解释」，必须有 live 证据。

## Non-goals
- 不做崩溃自动恢复框架
- 不做跨设备会话迁移
- 不做 soak（≥1h 长跑归 `FP-P2`）

## 演练矩阵（全部需 live，非 dry-run）
| 场景 | 期望 |
|------|------|
| 会话中 gateway restart | 会话可继续；ack 重新达成；journal 未丢 |
| 会话中应用重启 | 会话历史与 workspace 绑定恢复 |
| 增强会话进行到一半翻 kill | 当轮或下一轮起停止注入，无半生效 |
| kill 后 undo | 仍可 undo 已写入内容 |
| flag 关闭 rollback | 行为回到 baseline parity |
| 应用版本回滚（N → N-1） | 数据保留，flag 状态安全（不残留 ON） |
| restart 失败 | 明确报错与恢复指引，不静默 |
