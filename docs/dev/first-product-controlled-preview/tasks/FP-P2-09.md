## Goal（用户可见结果）
用户和 Agent 能安全创建整体评审、行评论、线程回复并更新允许的 PR metadata；代码或远端状态变化时，不会把评论或修改写到旧版本。

## Non-goals
- 不执行 merge、close/reopen 或 Issue 自动关闭
- 不实现 GitLab/Gitee 评论定位
- 不让 AI 自动发布 review

## Acceptance criteria
- [ ] review/comment/metadata mutation 全部经过 Main policy 与 typed host-api
- [ ] 行评论绑定 provider/repo/pr/headSha/path/side/line/bodyDigest
- [ ] 发布前重新读取 head SHA；旧 Diff 评论被拒绝并要求刷新
- [ ] metadata update 使用 `expectedUpdatedAt` 或等价 ETag/version guard
- [ ] 主效果成功、附属标签/参与者/刷新失败时返回结构化 partial success
- [ ] Agent 发起的远端副作用需要 action-bound approval，且 approval 单次消费
- [ ] 评论 snapshot 只保存最小 diff hunk/commit lineage，不保存不必要完整代码
- [ ] fixture/integration 覆盖 create/edit/reply/stale-head/permission-denied/rate-limit
