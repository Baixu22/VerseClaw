## Goal（用户可见结果）
用户能让 agent 在监督下完成一个有目标的浏览器任务，任务开始前有审批，结束时有成功判定；私网仍然被拒。

## Why this exists
私网 deny、Vault、approval/recovery backend 已有（前序 `TASK-P1-06` done），但 UI 直接 `createTask → runTask`，executor 主要只打开 URL，未真正执行 objective / success condition。也就是「安全壳完成、能力未完成」。

## Non-goals
- 不做无监督模式（**硬锁**）
- 不放开私网访问（**硬锁**）
- 不进 Controlled Preview 首发范围

## Acceptance criteria
- [ ] approval UI：任务开始前展示目标、目标站点、权限范围，用户显式批准
- [ ] objective executor：能执行多步目标，不止 open URL
- [ ] success verification：有明确成功判据与失败原因
- [ ] 私网 deny 回归通过（不得因新功能被绕开）
- [ ] 凭据只走 Vault，日志/截图不含凭据
- [ ] 公网 soak：连续任务稳定性记录
- [ ] E2E：approval → 多步执行 → 成功判定 → 失败路径
- [ ] 真人 10 次使用记录（G4）
