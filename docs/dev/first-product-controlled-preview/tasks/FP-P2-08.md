## Goal（用户可见结果）
用户和 Agent 能通过 Main-owned Remote Forge 读取 GitHub PR detail、commits、structured diff、checks、reviews 和 readiness，并明确知道结果是否完整。

## Non-goals
- 不发表评论、改 metadata、close/reopen 或 merge
- 不扩到 GitLab/Gitee
- 不替换 `hostApi.git` 的本地 Git 操作
