## Goal（用户可见结果）
产出「Verse Claw Windows x64 · DCS Coding + GitHub Forge Controlled Preview」内部分发包，附带范围声明、Forge 裁决、已知限制、支持渠道与回滚指引。

## Why this exists
这是 program 的交付点。它存在的意义是**把闸门写死**：只有前面全部门禁绿了才产包，避免又一次「本地绿灯即发布」。

## Non-goals
- 不进 public latest
- 不做公开发布公告
- 不宣称 `liveReady` / `productApproved` / GA

- 未签名产物仅限内部 Alpha，不进 public latest。

- 出闸不改变 `defaultOn=false`。
- 出闸不自动打开 Agent merge，也不授权生产 repository 远端副作用。
- 出闸不自动等于 UAS 开工；独立 proposal 现已应用，TF-0011 仅获工程治理实施权限，不获得 live/product/default-on 权限。
