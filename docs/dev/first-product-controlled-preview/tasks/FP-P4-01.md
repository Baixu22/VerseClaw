## Goal（用户可见结果）
用户在产品内完成完整的知识沉淀闭环：suggest → review → confirm/reject → retrieve，且确认前绝不写回。

## Why this exists
后端 golden path 已有 human confirm 且确认前不写回（前序 `TASK-P1-05` done），但 renderer 只有 facade，没有真正的 suggest/review 页面。因此这个能力对用户不可见 —— 属于典型 shelfware，只是尚未被首产品需要。

## Non-goals
- 不做自动写回（**永久硬锁**）
- 不进 Controlled Preview 首发范围
- 不做知识图谱可视化

## Acceptance criteria
- [ ] suggest 列表页：展示候选知识条目与来源
- [ ] review 页：可逐条查看 diff / 上下文
- [ ] confirm / reject 操作真实生效，reject 后不留痕（或留审计痕但不写回）
- [ ] retrieve 页：能检索已确认知识并在会话中引用
- [ ] 确认前**零写回**，用单测断言
- [ ] i18n en/zh
- [ ] E2E 覆盖 suggest→review→confirm→retrieve 与 reject 路径
- [ ] 真人 10 次使用记录（G4）
