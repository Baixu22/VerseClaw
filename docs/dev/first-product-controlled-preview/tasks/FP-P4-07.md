## Goal（用户可见结果）
日文 / 俄文用户在 Settings → Developer → DCS Production Flags 看到的是本地语言，
而不是夹在本地化界面里的英文。

## Why this exists
`FP-P0-04` 为 ack 状态机新增了 status 五态与 `ackHint.*` 七条文案。任务书要求
**en/zh 内容 + ja/ru 键位齐**，已照此交付：ja/ru 的这批键存在但值是英文占位。

这与该两语区**既有惯例一致** —— `settings.developer.dcsProdFlags` 下的既有条目
（`toggleLabel` / `viewToolsDiscover.*` / `observability.*` 等）在 ja/ru 里同样是英文占位。
所以这不是 `FP-P0-04` 引入的新债，而是把既有债扩大了一点。

## Non-goals
- 不改 i18n 框架或键结构
- 不做机器翻译充数（错译比英文占位更糟）
- 不阻塞 Controlled Preview（首发平台 Windows x64 / 首发语言 en+zh）

## 待补范围（`FP-P0-04` 新增部分）
| 键 | en 源 |
|---|---|
| `status.saved` / `.restarting` / `.runtime-acknowledged` / `.failed` | saved / restarting / runtime acknowledged / failed |
| `ackHint.gatewayNotRunning` | Saved. The gateway is not running… |
| `ackHint.restartFailed` | Saved, but the gateway restart failed… |
| `ackHint.ackTimeoutRunning` | Saved and restarted, but the runtime did not confirm in time… |
| `ackHint.ackTimeoutStopped` | The gateway stopped before confirming… |
| `ackHint.ackIncomplete` | The runtime replied with an incomplete acknowledgement… |
| `ackHint.staleGeneration` | Only the previous gateway process answered… |
| `ackHint.flagRejected` | The runtime did not adopt every requested flag… |

**另需一并处理**：`developer.dcsProdFlags` 下既有的英文占位（非本任务引入，但同一面板内
混杂两种语言比全英更差）。建议整块一起补。

## 实现要点
1. 先普查该两语区**全部**英文占位范围，别只补 ack 这 11 个键（否则面板仍是混杂状态）。
2. 术语一致性：`applied` / `pending restart` / `kill switch` / `gateway` 等需与该语区
   既有译法一致；建立小术语表。
3. `ackHint.*` 是**可操作提示**，翻译必须保住「下一步该做什么」的可执行性，不能只译字面。
4. 保持 CRLF 与既有文件一致；改动应为纯增量 diff（不重排既有键）。

## Acceptance criteria
- [ ] `FP-P0-04` 新增的 11 个键在 ja/ru 均为本地语言
- [ ] 该面板内既有英文占位一并补齐（或明确列出本轮不补的部分及理由）
- [ ] 术语表入档，与该语区既有译法一致
- [ ] `pnpm i18n:lint` 通过
- [ ] diff 为纯增量/改值，未重排既有键、未翻转行尾
- [ ] 每条 `ackHint` 译文保留可操作性（人工复核，非机翻直出）
