## 规则

1. 一任务 == 一文件。不要把实现塞进 STATUS。
2. 跨会话工作用任务文件内的 **Implementation slices**。
3. 高信息低密度：切片简短；链接代码而非粘贴 dump。
4. 每个切片后：追加任务 Progress log；更新 STATUS 注册表一行 + 开发日志一行。
5. 标 `done` 前逐条核对 DoD 五门禁，并在任务文档 `## Gate checklist` 打勾。
6. 上表任务收口时必须同步统一 Agent 开发日志；不得通过复制任务绕开 Task Forest 依赖。
7. `FP-P2-07`–`FP-P2-10` 不得抢跑当前 FP-P1；进入 P2 后严格串行，并与 `FP-P2-01/02/03` 共同完成阶段验收。
8. `FP-P2-07` 首切片创建 `harness/specs/tasks/remote-forge-controlled-preview.md`；`FP-P2-08`–`10` 只更新该共享 task spec，并在各自收口前运行 Harness、contract、i18n、typecheck 和 Electron E2E 门禁。
9. 2026-07-28 的 engineering-only sequencing deviation 只允许在 `FP-P1-07/08` G5 待验收时串行推进 P2 pre-canary 工程；它不表示 P1 出口通过，不授权真人 canary 或任何真实远端副作用。
