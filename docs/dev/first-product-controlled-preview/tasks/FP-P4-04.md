## Goal（用户可见结果）
Runtime Memory 在产品中被明确标注为 `diagnostics-only`：不参与生产注入，用户不会误以为「产品记住了我的项目」。

## Why this exists
RM 明确是 diagnostics-only，生产 attempt 也没有完整注入，且缺真实 corpus、质量门槛、治理与批准。本任务的工作**不是**让它上线，而是把「不上线」变成一个被守住的状态（标注 + 断言 + 不漂移）。

未来若进入长期 Memory 生命周期实现，唯一任务是 `TF-0018/UAS-07`。本任务只提供 diagnostics-only 基线和防漂移证据，不得提前实现候选批准、TTL、纠正、冲突或持久化主线。

## Non-goals
- 不做生产注入
- 不建 corpus（那属于 TF-0006）
- 不解阻 TF-0006
