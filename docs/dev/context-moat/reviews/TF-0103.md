### 为什么这仍然阻塞，而不是「显然可以放行」

1. **§R2.3 对该门明写「无豁免」。** §D4 建立的整套机制是：豁免必须是**显式白名单**，而 `lint:check` 不在任何白名单内 —— §D4 只分析了三个红门（`config-schema-parity` / `pnpm test` / `maturity:validate`），**漏掉了 `lint:check`**。
2. **§R2.0.1「门 = exit code，不 = 自述」。** 我若以「非本轮引起」为由自行放行，就是用判断力覆盖机械判据，而这正是 §D4 存在的理由（其 §0 原话：不先裁定分类，「L1 门整体 exit 0」就被既有红门污染，整个验收体系失效）。
3. **§R4.8「任一车道都不得自行放行 barrier」。** 里程碑门是收口判据，放行权不在单条车道。
4. 这与 TF-0142 要解决的问题**同类**：把门定义为「固定 exit-code 组全绿」在当前工作树上不可达。§D4 对三个门做了这件事，第四个门需要同样的裁定。
