# 会话模型选择

2026-11-06：模型按钮直接展开可用模型列表。用户点击一个模型即可使用，思考强度位于列表下方。移除“仅本条消息／本会话／始终”作用范围选择。

## 默认规则

| 场景 | 行为 |
| --- | --- |
| 新建会话 | 沿用最近一次主动选择且仍可用的模型；没有可用偏好时使用 Agent 配置的默认模型。 |
| 当前会话切换模型 | 保存成功后更新按钮，从下一条消息开始使用。历史消息保留。 |
| 返回已有会话 | 恢复该会话已保存的模型，不受其他会话最近选择影响。 |
| 首条消息 | 将输入区显示的模型保存到该会话，再发送消息，确保显示和实际请求一致。 |
| 队列消息 | 入队时保存当时的模型选择；出队发送沿用该选择。 |
| 保存失败 | 保留原模型，显示错误。首条发送的保存失败时，不发出模型请求。 |
| 保存期间切换会话 | 结果只更新原会话，不关闭新会话的菜单，也不覆盖新会话的模型或偏好。 |
| 最近使用的模型已移除 | 仅新会话回退到可用默认配置；已有会话的明确选择保留，供用户切换。 |

设置页继续负责 Agent 默认模型。输入区的选择不修改 Agent 全局配置。

## 实现

`resolveChatModelRef` 统一输入区和上下文状态区的模型解析。
`lastChatModelRef` 是本地设置中的最近选择，只有显式切换成功才更新。
`hostApi.sessions.patchRuntimeModel` 保存会话选择；发送参数中的
`persistModelSelection` 用于首次发送前落实继承值，`modelRefOverride` 将确定的模型带入实际请求。
现有单次请求的模型覆盖接口继续支持调用方显式覆盖。

加号轮廓通过阴影描绘，不占据布局空间，SVG 中心与圆形轮廓中心重合。
相邻菜单共用模糊消散动效、背景和间距，关闭中的浮层立即禁止交互。

会话控制卡片使用不透明的浅灰／石墨灰表面、细边缘和柔和阴影。输入框与弹卡不叠加背景模糊，避免聊天文字透入。模型菜单按“品牌图标、完整模型名、提供方”排列；长名称自动换行，窄窗口保留已选模型名。品牌图标来自 `@lobehub/icons`，按模型家族识别 DeepSeek、Grok 等模型，包括经由路由提供方接入的模型。

Git 输入区与会话环境卡根据 Host 返回的工作树列表区分主检出和关联工作树；分支名、游离 HEAD 与工作树身份分别呈现。弹卡只保留必要的分组说明，思考强度在模型列表下方展开。

## 调研依据

使用 VerseSearch / AnySearch 检索并读取 Microsoft 官方文档：
[AI language models in VS Code](https://code.visualstudio.com/docs/agent-customization/language-models)。
其模型选择器直接提供模型；新对话偏好与已有对话模型分别处理。
本项目在此基础上采用“新会话最近选择、旧会话恢复、下一条生效”的默认规则。
缓存风险提示继续使用现有判断，仅在检测到实际风险时出现。
