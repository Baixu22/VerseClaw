# Context Packs

Context pack recipes define the smallest useful reading list for a task. Keep them short enough for an agent to load before implementation.

These recipes are not injected Context Packs and are not durable task truth. Runtime Context Pack assembly should pull from Task Ledger, specs, memory, and observability as appropriate.
