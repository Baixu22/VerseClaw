# P7-004 ? Quarterly maturity audit and phase review

Owner: program-governance
Reviewer: security-lead
Findings: F-GOV-002,F-GOV-003
Depends on: P7-001,P7-002,P7-003

## Goal

Every quarter re-roll coverage, risk acceptance deadlines, evidence freshness, and release eligibility.
Agent Dev grade/releaseReady must never be extrapolated to whole-system release readiness.

## Scope

maturity scorecard, risk acceptance, phase status, release decision, continuous governance gates.

## Tests

- pnpm agent-dev:audit
- pnpm agent-dev:deep-test:reuse
- pnpm run typecheck
- pnpm run test:e2e:agent-dev-quality:run
- quarterly audit dry-run (`pnpm maturity:quarterly -- --dry-run`)
- pnpm harness validate --spec harness/specs/tasks/system-maturity-quarterly-audit.md
- pnpm maturity:seal

## Acceptance

- [x] A1: All phase statuses are traceable
- [x] A2: Risk acceptance entries have non-expired reviewBy deadlines
- [x] A3: Incomplete P0/P1 automatically blocks release

## Gate policy

- Primary Agent Dev audit gate is `pnpm agent-dev:audit` (strict). `agent-dev:audit:report` is report-only.
- Deep-test evidence may use `pnpm agent-dev:deep-test:reuse` when a fresh Vite build already exists, but the same evidence pack must also include required full gates:
  - `pnpm run typecheck`
  - `pnpm run test:e2e:agent-dev-quality:run` (run `pnpm run build:vite` first only when dist is missing/stale)
- Harness must pass on the final commit tree (not only mid-collection).

## Delivery

Follow DELIVERY-FORMAT.md. STATUS=done only after post-commit harness + evidence + quarterly dry-run all pass.
