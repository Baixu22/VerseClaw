# P6-003 — Bundled binary、installer 与 Action 内容固定

Owner: supplychain-release
Reviewer: security-lead
Findings: F-SUPPLY-002
Depends on: P0-001

## Goal

构建下载物、安装工具和 GitHub Actions 具备 checksum、version 和 commit pin，并在使用前 fail closed。

## Scope

bundled uv、agent-browser、bundled Node、ossutil、GitHub Actions。

## Tests

- `pnpm exec vitest run tests/unit/supply-chain-integrity-p6-003.test.ts`
- `pnpm run release:supply-chain-policy`
- `pnpm run release:supply-chain-policy:live`
- checksum mismatch deny probe
- offline verified file download test
- workflow YAML parse and Action pin scanner
- `pnpm harness validate --spec harness/specs/tasks/supply-chain-integrity-pinning.md --since 4e3c6eb58`
- `pnpm run release:supply-chain-policy:evidence:full`

## Acceptance

- [x] A1: 外部二进制 hash/signature 必须匹配；14 个 uv、agent-browser、Node 和 ossutil 资产具备固定 HTTPS URL、version、size 与 SHA256，校验失败不落盘或解压；live probe 已核对当前上游 digest/SHASUM/bytes。
- [x] A2: 禁止未经校验的 `curl | sudo bash`；OSS 发布改用 job-local pinned ossutil archive，校验后才执行。
- [x] A3: GitHub Actions 使用 commit SHA；全部 8 个外部 Action 仓库由 manifest 注册并以 40 字符 commit 固定。
