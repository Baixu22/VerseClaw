## Acceptance

- [x] A1: 客户端明确定位正确 feed；Main 按已安装版本固定选择 HTTPS stable/alpha/beta 目录，Renderer 不能覆盖。
- [x] A2: 篡改 metadata 或 package 拒绝安装；redirect、来源、channel、SHA512、size 和下载后文件均 fail closed。
- [x] A3: feed 来源和 channel 可审计；策略、workflow gate、focused tests 和证据清单已落盘。

## Validation note

2026-07-17 stable live feed probe 在显式启用 TLS 证书校验的环境中通过。若 `NODE_TLS_REJECT_UNAUTHORIZED=0`，运行时更新检查和 live probe 均 fail closed。alpha/beta 端点尚未发布 metadata 时返回 404；客户端仍选择对应固定目录并 fail closed，不回退到 stable 或未知来源。
