# Phase 3 Provider Tool Registry Real Producer Diagnostic Consumer Validation

This task tightens the Registry diagnostic consumer boundary. It does not expand authority. It validates producer-generated diagnostics from existing context, tool/MCP, and TaskLoop shadow seams while preserving default-off, in-memory, diagnostics-only behavior.
