id: rsi-semantic-training-boundary
title: Ground experience in public task behavior without revealing the oracle
type: ai-coding-rule
severity: error
---

1. A semantic training view uses an explicit new version. Derive its contract only from the verified original public prompt, acceptance criteria, public declaration projection and public error convention; preserve the original task role and outcome.
2. Treat public executor documentation as a reference for using tools. A diagnosed transaction or return-value bug concerns the task implementation; do not relabel an existing executor guarantee as a learned repair.
3. Never send hidden vectors, reference bodies, private assertion payloads or final-task content to generation. A changed or oversized contract is rejected before a model request.
4. Keep original trials, candidate text, source hashes, requests, failures and billing ledgers immutable. New views, models and protocols receive separate plans and identities.
5. A generation-only pilot establishes input fidelity and candidate applicability, not benefit. Subsequent validation and final populations are independently frozen before a measured candidate; task counts, headroom and five-point detection power are separately justified.
6. Existing quality, safety, cost, budget and product-default protections remain. No diagnostic, perfect-treatment counterfactual or successful generation can promote an old failed candidate.
7. Generation authorization binds the new run and source commit, with explicit tokens, calls, currency and spending limit. Offline controls authorize zero provider calls; retained request attempts and replay must preserve those limits.
8. A prospective corpus check verifies the exact test-file identities, assertion coverage and frozen workspace bytes. A baseline module intentionally absent from its historical revision may fail import; unrelated missing dependencies and process errors cannot establish baseline difficulty.
9. Headroom pilots freeze family selection before dispatch and reserve the entire source prototype for exclusion from subsequent measurement. Three repeats produce one case-level pass-cubed result. Require a complete independent grade and known usage for every slot; scripted controls and ungraded format failures cannot qualify model headroom.
10. A headroom authorization binds its run, source commit, full plan digest and exact resource envelope. Replay checks the original ledger, preflight, responses, effects, graders and admission artifacts. Missing or changed evidence fails closed; an interrupted attempt is retained without a retry.
11. Measured semantic populations use a new version and bind each family review to its upstream identity, public contract, reference and oracle. Renamed locals, changed literal parameters and repeated source records do not create independent tasks. Live admission requires committed population bytes and replay of the pilot through its original source checkout.
12. Measured generation, validation and final dispatch each require a new phase authorization bound to the complete plan. Final replay charges generation tokens alongside all task attempts, verifies both complete splits and joins the confirmed principle to the production hook and off-on-off path. Scripted controls remain NO_GO with zero model requests.
13. Stdin/stdout populations bind language runtime, public source path and family identity. Reference bodies and official tests remain private; reference-revision oracles are restored by digest for both empty-baseline and reference calibration. Incomplete prompts, duplicate implementation shapes and insufficient official tests reduce admission before model dispatch. Record native execution environments; a denied Windows C++ binary is an infrastructure failure, not a reference or model result.
14. Freeze each measured C++ task's compiler profile and version before generation. Generated source cannot select another toolchain. Calibration may collect rejected reference families for deterministic backfill; failed reports cannot produce a population seal. Resume verifies reference source bytes and private input digests, retains interrupted evidence, and preserves an existing sealed identity.
15. Native admission classifies the same public event as production: the complete serialized public request is the prompt and frozen instructions remain the system prompt. The production classifier recognizes complete supported stdin/stdout task contracts before incidental source URLs or deployment vocabulary. Admission must preserve its result without substituting an evaluator-only task type. Study resume validates its settled ledger and each retained receipt before dispatch, refuses a gap or an unsettled request, preserves original reports and writes a new recovery report.
16. An executor continuation creates a separate v2 population identity with the original population digest and executor path. Replay verifies both seals, both source bindings, unchanged task/metric/grader/dependency bytes and the original calibration artifacts. Only explicitly listed orchestration files may differ. Generation and studies bind the new source; registry provenance continues to identify the original calibration source.
17. New prospective populations bind the complete committed observed cohort before calibration. Canonical upstream identities exclude whole observed families, including alternate Codeforces URLs, and cannot cross new validation/final families. APPS and TACO function-call tests stay rejected by the default string-pair parser; the explicit `json-stdio` adapter emits one JSON-argument stdin vector per function case and structurally compares one JSON return value. TACO function records preserve their serialized source vectors and pinned identity. A packed stdin/stdout batch stays one official vector. Measurement-ready reads reject missing or changed observed-cohort bindings.
18. APPS and TACO line-list I/O uses an explicit `newline-lines` adapter bound to the publisher's newline-join contract. Accept string members only, preserve their whitespace and serialized source vectors, and keep each complete input/output list pair as one official vector. Reference calibration uses the frozen native text grader.
19. Offline cross-source census binds source shards, historical records and official vectors by digest, then resolves identity bridges after every source has been read. Complete publisher identity inventories include records omitted by vector or reference screening; their prompt, URL and native source/name identity participate in whole-family exclusion through the importer’s identity rules. Full native-vector screening has a separately frozen selection. Parsed string-vector transport retains original source and serialized I/O digests; function vectors retain serialized numeric literals. Native alternate-reference checks preserve raw process diagnostics and stop on incomplete or malformed worker output. Retained-report replay verifies the original report digest and reproduces the grades without executing submissions.
20. Complete-native census does not promote legacy base candidates past current vector screening. Base credit requires a screened source in the same complete identity component; other entries retain their identities in a held tier. Candidate component exports bind all member keys and eligible alternatives. Implementation review joins repeated shapes across whole components and excludes historical shape matches before calibration or split admission.
21. Native continuation verifies the frozen archive or retained source-copy digests and the independent verifier before dispatch. New native runs copy and bind their worker before use; the worker verifies its own bytes, and source drift stops later dispatch. A pending family with an existing started directory remains unsettled and cannot be retried. Malformed worker records and missing materialized files retain infrastructure receipts and bound raw diagnostics. Shape-review source bindings include every wrapper that changes tier credit.
22. Private native checkers use a separately bound v1 checker contract and v2 oracle report. Their source bundle, compiler, execution profile, reference and complete original vectors stay outside public task inputs and the model baseline. Candidate compilation and execution have an independent root, an unprivileged user, no new privileges and no capability bounding set. Only completed subject and checker exit-zero results pass. Replay verifies candidate source, copied worker, payload, native binaries, process records and raw logs. Subject compile or test failures remain assertion outcomes; incomplete or invalid worker/checker execution is infrastructure and stops calibration or measurement admission. Source qualification and later checker grading retain their separately frozen run envelopes.
23. New private worker v2 records verify successful entry into the isolated helper and the actual subject exit code before grading. Wrapper failure, missing/malformed launch evidence and setup errors cannot establish a compilation or model failure. The launcher marker descriptor stays outside submitted processes. After normal completion, PID namespace teardown clears descendants; timeout cleanup never signals an already reaped process group.
24. Independent native replay preserves JSON field types. Boolean values cannot stand in for PID namespace identifiers, vector indices, counts or model-request counters. Coherently changed launch records still fail when their command, timeout, actual exit or protocol differs from the frozen contract.
25. Full Library Checker calibration binds a clean executor, the complete ordered input selection, registry commit and resolved task identity in immutable phase receipts. Continuation accepts only a contiguous family/phase prefix and never restarts a started phase without its receipt. Infrastructure outcomes retain raw report/log/evidence digests and a terminal marker. Memory pauses keep every frozen official vector; source calibration remains a zero-model-call control until separately admitted to measurement.
26. Prospective source queues bind complete component membership, known-shape partitions, raw supplemental record digests, executor and seed before calibration. Preserve all source alternatives and historical exclusions; verify whole-index coverage and original census counts. Base credit requires a current screened source. Frozen family/source order controls unstarted backfill after reference assertion rejection; infrastructure stops dispatch. Final splits use native-qualified whole families.
27. New isolated Python execution uses a separately bound v1 descriptor and v3 oracle report. Freeze interpreter/reference/resource settings before dispatch. Reuse the verified native unprivileged PID-namespace launcher; submitted code cannot access private oracle files or inherited credentials. Preserve raw output, launch/exit records, copied worker/helper bytes and compiled bytecode. Independent disk replay binds worker/helper bytes to the frozen executor and each operation's logs to its role and vector index. Missing-source reports require the source to be absent, complete baseline rows and a failed verdict; infrastructure reports cannot pass. Completed exit-zero executions and original text normalization define correctness. Historical v1 reports preserve their frozen contract.
28. Native target headroom uses a v2 pilot bound to the complete reviewed pool and committed observed history. Reserve twelve distinct families before outcomes using proportional execution strata and fixed hash rank, with at least one family per runtime/toolchain stratum. Keep the existing v7 collector, three off-only repeats, reference calibration, 0.8 headroom ceiling and 145-call/2M-token/zero-cost envelope. Exclude every selected family from later measurement; remaining case bytes and the pilot plan's preassigned split must remain fixed. The prototype pilot cannot establish native target headroom. Scripted pilots remain unmeasured and cannot authorize provider calls.
29. Constructed task asset admission reads declarations from the collector's canonical publicContract.declarations. Factory-produced tasks must pass the same public/private-path separation checks as native tasks; unit fixtures must not add a duplicate top-level declaration list to satisfy the verifier.
30. Reserve validation/heldOut membership before native pilot outcomes. Keep all remaining families and derive the minimum target from the existing per-split power requirement plus the twelve excluded pilot families (currently 6276). Allocate existing positive/negative anchors and at least three reviewed safety cases per split before hash-ranked balancing. Never create missing labels. Insufficient counts or coverage block live pilot preparation. Measurement-pack export verifies the target and recomputes the reservation before writing a new artifact; it cannot authorize model requests or claim measured headroom.
31. Official USACO source intake binds the result-page problem/solution/archive links and all downloaded snapshots. Reference selection records an explicit code-block index, digest and full-credit review basis; a page's first solution may be partial-credit code. Preserve all paired official tests without newline conversion. Reject incomplete, duplicate, unsafe or oversized archives before writing candidates. Source intake remains pending whole-family review and native calibration and cannot add qualified families to an existing frozen queue.
32. USACO family review rebuilds source candidates from the bound original snapshots, then joins the complete frozen queue and observed task packs by canonical identity, public prompt and the existing implementation-shape function. Resolve connected families after all additions so a late bridge propagates historical exclusions. Only new Python components can produce the separate USACO calibration plan; preserve every source vector and the existing isolated execution profile. Native calibration input loading checks the copied family review and source membership before starting. Known-component review and source preparation add zero qualified families; semantic independence and native outcomes remain separate evidence.
33. Official-source calibration retains public sample visibility and requires a reviewed output comparison bound to the source snapshots. Excluded members in the frozen base-family manifest participate in connected-component exclusion by identity, prompt and reference shape.
