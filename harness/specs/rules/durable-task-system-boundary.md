title: 持久任务身份与单写者执行边界
type: ai-coding-rule
severity: error
---

产品 Task Ledger 是任务定义、修订与业务完成事实的 owner；Task Forest 是研发 skill，不得成为产品运行依赖。运行和工具效果继续由既有 runtime owner 记录。

任务身份独立于会话、run 和工作树。规范化仓库域内的同一任务只允许一个有效实现 claim。领取、幂等键检查与事件记录必须共享事务；同 key 异参拒绝。相似标题不自动合并任务。

目标契约有版本、来源和验收标准；上下文压缩不修改目标。执行前从 owner 读取目标和 binding；核心目标预算不足或 owner 不可用时停止受管副作用。

owner epoch 单调递增；过期租约不证明旧进程停止。交接前核对在途操作，旧 epoch 在实际受管工具入口和结果提交处拒绝。任务归属、资源占用与会话引用分开记录。

同一会话代次、同一工作树在自然租约过期后，可以在原任务事务内通过新 epoch 继续尚无未决效果的任务。新 epoch 拒绝旧凭据的后续操作；未知或在途效果、显式暂停、会话代次变化和时钟回退继续拒绝自动接续。

首次工具准入携带准备时捕获的任务 ID 和 epoch，Main 在原任务事务中核对该 owner 后接续。准入 ACK 丢失后，同一请求回读已提交的决定；模型上下文仅凭原任务表中同一 run 的准入更新凭据。显式交接后的旧 run 不能借首次工具调用取得新 epoch。
同一 run 的会话准入 ID 与 executionRevision 在自然续租时保持稳定，Task credential 使用新 epoch；每个工具操作以稳定 operationId 形成独立准入请求。同一 run 的工具集合共享已确认准入，旧 run 和显式交接继续使用原边界拒绝。

完成必须回读绑定同任务、版本、候选的真实检查与产物。执行结束、模型自述和状态投影不能自行授予完成。降级保留目标、产物与可恢复状态。

独立评审绑定提交事件序号、候选文件、任务版本、执行 epoch 与负责人代次。提交后使用只读角色派发评审，回读 Registry 的终态和明确判定；较新的待完成或失败评审不能退回使用旧通过记录。评审预留与回执持久化，派发结果未知时禁止再次派发。

评审通过还必须有该 reviewer 对候选文件的成功读取记录：提交序号、运行身份和文件摘要匹配，实际返回内容覆盖需要评审的文件。普通只读 observer 不占用 verifier 名额。Runtime 明确未派发的失败允许重试；已派发或未知结果须从原委派与终态记录核对。

需要有限修复的任务契约明确 `maxRepairAttempts` 为 0 或 1。修复沿同一任务保留目标与验收，在账本事务中消费次数并使旧检查失效；重试、重启、交接和修订均不能重置次数或提高上限。新的提交须重新检查实际整合产物并取得新的独立评审。

任务分解保留所有祖先目标，子任务继承父约束。活跃子任务存在时拒绝修订父计划；取消计划先禁止新副作用，再等待后代操作结清。已结清的旧计划通过显式修订保留历史后替换。

项目计划写入仅接受 Workspace 已登记的项目负责人和 Runtime 当前会话代次。计划、子任务与修订事件同事务提交；修订记录理由和新旧任务引用，旧验收不能用于新任务。暂定假设和待决事项不作已确认事实。

领取计划下一项必须核对当前计划 ID 与版本，在同一事务检查项目已有执行者、前置任务验收并领取。重试不得换领其他子任务。托管派发已有账本预留但找不到 Main 回执时，按结果未知处理，不得再次派发。

效果恢复只消费已有 owner 的回执，核对 session、run、tool call、工具种类、时间及当前 epoch；相同回执可重试，冲突回执拒绝。事件消费使用持久序号，未确认事件重送；缓存始终可从原始事件重建。

工作树回收读取历史 checkpoint、验收与委派产物。任务完成不会解除产物引用；只有原 Task 事件已记录可回读的 Git 保留回执，且删除前再次核验精确 SHA256，才允许回收对应路径。保留回执先提交，删除完成另记事件；重启使用原 authority 身份续接。首次任务建库、跨域登记和清理共享执行域锁，活跃领取、委派及未决效果继续阻止回收。

Runtime、Git 菜单与存储页复用原工作树 owner 的隐藏索引检查。assume-unchanged、skip-worktree 和忽略文件不作为已保留内容；检查保持用户索引标记。进程内回收核对所有现存文件、删除差异及权限的保留副本，根目录权限按创建基线校验。确认无删除效果的原生脏文件拒绝结算为 not-applied 并恢复生命周期；未知删除效果继续占用原 writer，不能以路径仍存在推断无效果。

UI 原生检出删除在权限确认后，将最终 owner/身份检查与有界原生 Git 删除一起置于原执行域屏障内。最后一次检查与删除之间不得释放屏障；并发首次任务建库、领取和登记在屏障后重新核对检出身份。

完成通知携带派发时持久保存的负责人代号；投递、直接 agent 调用与事务更新都检查该代号。换代和删除的旧完成通知持久标记失败并停止重试，不能借较新 child run 的代号启动负责人。

交接保留源会话的历史与代号。完成通知从 Workspace owner 回读交接状态，拒绝已交接的旧负责人；Task Ledger 在转移 writer 前核对待结清操作，转移后用新 epoch 继续同一 checkpoint。

同一 writer epoch 恢复中断运行时，账本须核对原运行进程确已退出、任务仍在执行且无 started 或 unknown 效果。进程仍存活、缺少进程身份或退出状态未知时保留原运行。替换运行与记录旧、新进程和运行身份须在同一事务提交。

手动暂停派发时，取消已有任务与核对已有操作效果继续使用原会话、代次和写入资格。已移交、归档、无效或代次变化的绑定不能借此操作，取消引发的运行停止须携带原会话代次。

委派写入者保持原代次直到 Runtime 确认停止且效果已结清。Registry 替换运行时保留首次派发身份，用原身份核对任务取消与委派结算。取消后的完成不进入负责人续行。项目执行者终态失败且已结清时释放写入权，保留未验收的暂停任务和检查点；只有真正验收的任务才能解锁依赖。

追溯读取原 Task 事件与效果、checkout、artifact owner 的回执。运行和操作的开始、结清及原执行身份须持久保留；当前投影不能为历史补造来源。执行域登记消费原 Task owner 的 schema 版本，版本检查保持精确匹配。

模型用量在实际请求开始时绑定原任务、会话代次、角色和运行/重试身份，结算不能改签给新 owner。协调者的只读引用只记录其自身用量，执行资格仍属于原 writer。相同调用重复观察幂等，冲突回执明确诊断；费用汇总去重原调用，金额或价格未知时不补零。

取消等待活动运行和未决效果，停止失败保留 cancelling。已释放协调者的取消使用原 run 身份，不能停止后来换选的其它任务。心跳失效保留终态清理所需的运行记录。

归档恢复按 Runtime 确认的旧、新会话代次迁移任务，writer 换代与只读引用迁移保持独立。未决运行或效果阻止 writer 迁移，旧代次和旧 epoch 拒绝。新运行恢复暂停任务时使用暂停后的 epoch，不能复活暂停前运行。

前后工具边界共享工具及参数的只读判定，未知工具和带副作用命令仍需领取。搜索命令通过预处理器或 hostname helper 调用外部程序时，同样需要有效领取。Git diff/show/log 只读准入要求在路径参数前显式关闭 textconv 与 external diff；启用外部分页程序继续要求领取。副作用准入按任务身份查询并提交事件，避免生成全量列表；父任务来源读取派发时保留的持久身份。界面异步回调按会话、工作区、代次和请求版本更新，迟到结果保留原作用域。

报告核对来源修订、候选、检查回执和产物 SHA256，按原执行范围验证或由原 retention owner 读取保留内容。删除会话不删除唯一任务验收，读取报告不改写任务、权限、资源或验收状态。
