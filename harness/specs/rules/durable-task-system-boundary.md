title: 持久任务身份与单写者执行边界
type: ai-coding-rule
severity: error
---

产品 Task Ledger 是任务定义、修订与业务完成事实的 owner；Task Forest 是研发 skill，不得成为产品运行依赖。运行和工具效果继续由既有 runtime owner 记录。

任务身份独立于会话、run 和工作树。规范化仓库域内的同一任务只允许一个有效实现 claim。领取、幂等键检查与事件记录必须共享事务；同 key 异参拒绝。相似标题不自动合并任务。

目标契约有版本、来源和验收标准；上下文压缩不修改目标。执行前从 owner 读取目标和 binding；核心目标预算不足或 owner 不可用时停止受管副作用。

owner epoch 单调递增；过期租约不证明旧进程停止。交接前核对在途操作，旧 epoch 在实际受管工具入口和结果提交处拒绝。任务归属、资源占用与会话引用分开记录。

完成必须回读绑定同任务、版本、候选的真实检查与产物。执行结束、模型自述和状态投影不能自行授予完成。降级保留目标、产物与可恢复状态。

任务分解保留所有祖先目标，子任务继承父约束。活跃子任务存在时拒绝修订父计划；取消计划先禁止新副作用，再等待后代操作结清。已结清的旧计划通过显式修订保留历史后替换。

项目计划写入仅接受 Workspace 已登记的项目负责人和 Runtime 当前会话代次。计划、子任务与修订事件同事务提交；修订记录理由和新旧任务引用，旧验收不能用于新任务。暂定假设和待决事项不作已确认事实。

领取计划下一项必须核对当前计划 ID 与版本，在同一事务检查项目已有执行者、前置任务验收并领取。重试不得换领其他子任务。托管派发已有账本预留但找不到 Main 回执时，按结果未知处理，不得再次派发。

效果恢复只消费已有 owner 的回执，核对 session、run、tool call、工具种类、时间及当前 epoch；相同回执可重试，冲突回执拒绝。事件消费使用持久序号，未确认事件重送；缓存始终可从原始事件重建。

工作树回收读取历史 checkpoint、验收与委派产物。任务完成不会解除产物引用；只有原 Task 事件已记录可回读的 Git 保留回执，且删除前再次核验精确 SHA256，才允许回收对应路径。保留回执先提交，删除完成另记事件；重启使用原 authority 身份续接。首次任务建库、跨域登记和清理共享执行域锁，活跃领取、委派及未决效果继续阻止回收。

Runtime、Git 菜单与存储页复用原工作树 owner 的隐藏索引检查。assume-unchanged、skip-worktree 和忽略文件不作为已保留内容；检查保持用户索引标记。进程内回收核对所有现存文件、删除差异及权限的保留副本，根目录权限按创建基线校验。确认无删除效果的原生脏文件拒绝结算为 not-applied 并恢复生命周期；未知删除效果继续占用原 writer，不能以路径仍存在推断无效果。

UI 原生检出删除在权限确认后，将最终 owner/身份检查与有界原生 Git 删除一起置于原执行域屏障内。最后一次检查与删除之间不得释放屏障；并发首次任务建库、领取和登记在屏障后重新核对检出身份。

完成通知携带派发时持久保存的负责人代号；投递、直接 agent 调用与事务更新都检查该代号。换代和删除的旧完成通知持久标记失败并停止重试，不能借较新 child run 的代号启动负责人。

交接保留源会话的历史与代号。完成通知从 Workspace owner 回读交接状态，拒绝已交接的旧负责人；Task Ledger 在转移 writer 前核对待结清操作，转移后用新 epoch 继续同一 checkpoint。

同一 writer epoch 恢复中断运行时，账本须核对原运行进程确已退出、任务仍在执行且无 started 或 unknown 效果。进程仍存活、缺少进程身份或退出状态未知时保留原运行。替换运行与记录旧、新进程和运行身份须在同一事务提交。
