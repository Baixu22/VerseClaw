# Harness Workspace Memory

This directory is for local agent working memory.

Commit this README and `schema.md`. Do not commit personal journals. Put private notes under `harness/workspace/<developer>/journal-*.md`; the root `.gitignore` excludes those developer directories.

When a note becomes a reusable team convention, distill it into `harness/specs/rules`, `harness/specs/guides`, or `harness/specs/layers` instead of committing the raw journal.
