# Harbor 演练发布检查清单

依据 `docs/harbor-guide.md`（批次比例：5%、20%、100%；观察窗口每批10分钟；暂停条件：错误率连续3分钟高于1.5%，或p95延迟连续3分钟高于1200毫秒）。

## 1. 发布前
- 确认发布负责人为沈宁，明确各批次时间点。
- 核对批次比例顺序：5% → 20% → 100%。
- 确认监控可观测错误率与 p95 延迟指标，且采样粒度支持"连续3分钟"判断。
- 确认可回滚到上一稳定版本，并准备好记录触发指标和时间的模板。

## 2. 逐批观察
- 每批放量后保持10分钟观察窗口。
- 持续跟踪错误率是否连续3分钟高于1.5%。
- 持续跟踪 p95 延迟是否连续3分钟高于1200毫秒。
- 每批观察结束后记录结果，再进入下一批次。

## 3. 暂停回滚
- 任一暂停条件触发时立即停止后续批次。
- 恢复上一稳定版本。
- 记录触发的指标名称、数值和时间点。

## 4. 24小时内复盘
- 发布结束后24小时内补齐复盘结果。
- 经验仅作为候选记录，需人工确认后才能写入正式知识。
