# Line C Grounding Shadow Consumers Readiness

This handoff covers the post-spine readiness layer for explicit shadow consumers of `GroundingRef` and `GroundingQuery`.

Allowed work is limited to readonly, local, bounded, default-off, summary-only, non-authoritative helpers/adapters, tests, and synthesis. Runtime cutover, provider registration changes, persistence, raw retention, memory promotion, renderer transport changes, and patch application remain out of scope.
