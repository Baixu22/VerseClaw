## 2. Gate 语义（无人类输入）

`evaluateCompactionPromotionGate` 是纯 fail-closed 函数：

- `shadow`：永远允许。
- `would-retry` / `provider-pressure-pilot`：需要
  `fixedProductionPairedSamples>=30` 且 `modelIndependenceOk=true`。
- `critical-only` / `limited`：需要 P6-A 全部自动指标：
  - fixed samples>=30
  - modelIndependenceOk=true
  - criticalDroppedSamples=0
  - schemaFreeMajorOmissionRate<=0.10
  - realContinuationCriticalActionRate>=0.95
  - staleLeakageSamples=0
  - completionDelta<=0.08
  - noFabricationRate>=0.98
- 任何缺失 evidence 都变成 missing reason，不伪造通过。
- 不再存在 `humanScoredSamples` / `humanRaters` 字段或 missing reason。

`assertModelIndependence`（runner / test helper）不再接受 human-rating
override。它要求 compressor model 与所有已配置的 judge/schema-free/
continuation/critic model 不同；P6-A 固定为 compressor=`deepseek-chat`、
其余=`deepseek-reasoner`。
