## 2. 数据流与 authority

- `compression-artifact.ts` 仍是 CompressionArtifact 的唯一 authority；`schemaVersion` 保持字面量 `1`。
- `semanticAtoms` 在 `CompressionArtifact` / `CompressionArtifactInput` 上是 optional；旧 v1 payload 无该字段时 normalize 输出中不生成该字段。
- `buildDeterministicCompressionArtifact` 接收 optional `semanticAtoms` 和 `previousArtifact`，先生成 atom ledger，再由 adapter 从 ledger 生成 legacy `objective/constraints/decisions/failedAttempts/nextAction/currentState/reviewNeeded/unverifiedClaims`；Markdown summary 与 recovery projection 仍只是 projection。
- `prepareCompaction` 从最近一个 `CompactionEntry.details.artifact` 提取并 normalize `previousArtifact`；`compact` 将该 artifact 传给 builder。superseded atom 保留并标记 `status: superseded`，不删除。
- Gateway schema 与 `shared/host-api/contract.ts` 同步声明 optional `semanticAtoms`；Electron `mapCompressionArtifact` 对 `semanticAtoms` 显式 normalize，不再只依赖 unknown spread。
- CRK authority 未变化：`requiredSelectors` / `staleReferences` / `blocked` / `failedAttempts` / `nextAction` 的 resolution 仍由 recovery.ts / recovery-default.ts 原有逻辑消费。

## 5. 指标变化

- `CompressionArtifact.schemaVersion` 仍为 `1`。
- 新增 atom 上限：每 artifact 48 个、atom.text 240 字符、evidence refs 每个 atom 8 条。
- critical atom 缺 evidence：builder/normalizer 从 `verified` 降级为 `unverified`，写入 `quality.warnings: ["critical_atom_missing_evidence"]`；Electron boundary 同样降级。
- recovery projection 增加 `semanticAtoms: verified=N unverified=N stale=N superseded=N conflicts=N` 计数和最多 10 条 bounded ledger 行。
- 未声明 token savings、judge 分数或单模型自评成功。
