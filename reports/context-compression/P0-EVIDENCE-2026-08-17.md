## 行为变更

1. 不可解析的 transcript-tree junction/链接被记录为 `realInventory.skippedInputs`，
   不再中断采样；默认 `~/.openclaw` 根目录冒烟可发现 2 个 ENOENT junction。
2. Manifest v2 固定六类 cohort：provider / pressure / turn count / split-turn /
   previous-summary / file-hunk，并保留 v1 manifest 的回放兼容（v1 manifest 30/30 回放通过）。
3. 报告新增 manifest digest、transcript inventory hash、model ids、prompt versions 和
   运行参数。
4. Hard Gate 对齐统一质量门槛：
   - L1: critical mean >= 0.95、critical min = 1（每样本 critical dropped = 0）、
     important mean >= 0.85、weighted mean >= 0.90、stale leakage = 0。
   - L2 schema-free: major/critical omission <= 0.10。
   - L3: first/critical action >= 0.95、no repeated work >= 0.98、
     contradictory action = 0、completion delta <= 0.08。
   - compression ratio 和信息密度仅作 advisory，不再作为 pass/fail 门槛。
5. L1/L3/cohort 指标同时输出 mean、min 和 95% CI（L1 连续指标 normal-95，
   L3 二值指标 Wilson-95）。
